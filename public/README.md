# Public Folder

Place your static assets here:

## Profile Image
- Place your profile photo as `profile.jpg` to display it in the Hero section

## Resume PDF
- Place your resume PDF as `resume.pdf` for the Download CV button
- When clicked, it will download as `Ketema_Bogale_CV.pdf`

## Project Images
- Place project screenshots in `assets/images/`
- Reference them in `src/data/projects.js` as `/assets/images/filename.jpg`
- Example: `image: '/assets/images/hotel-booking.jpg'`
